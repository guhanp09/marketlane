# Five-minute review

1. Read the problem and measured evidence in the README.
2. Open the decision/evaluation report in `reports/` and inspect its limitations.
3. Run the documented CLI from a clean Python 3.12 environment.
4. Read `docs/decisions.md`; inspect an edge case and its test in `tests/`.
5. Distinguish the implemented capabilities from the planned user research in `docs/product-brief.md`.

This repository records work implemented in November 2026. No historical users, interviews or commercial outcomes
are implied. The data source and any simulated assumptions are documented alongside the results.
